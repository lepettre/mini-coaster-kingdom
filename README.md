# Mini Coaster Kingdom

**Ein experimentelles, nicht kommerzielles Achterbahn-Puzzle im Browser.**
Isometrische Pixel-Art im Hochformat, gebaut für das Smartphone. Das ganze Spiel ist eine einzige HTML-Datei, ohne Server, ohne Tracker, ohne Nachladen.

> *English summary:* An experimental, non-commercial isometric pixel-art roller-coaster puzzle for the browser. You build a track from pieces so that each guest group enjoys the ride. Single HTML file, no tracking, no external assets. Everything – graphics, music, sound – is generated by code.

## Was das Spiel macht

Du baust in einem kleinen Freizeitpark eine Achterbahn – Teil für Teil, vom Lifthill bis zurück zur Station. Danach fährt der Zug, und die Gäste bewerten die Fahrt:

- **Gäste:** Kinder, Familien, Teenager und Thrill-Fans wollen jeweils eine andere Mischung aus Aufregung und Übelkeit.
- **Physik:** Der Zug braucht Schwung. Abfahrten geben Schwung, Anstiege und Kurven kosten ihn; ein Looping braucht viel davon. Wer zu wenig hat, bleibt hängen und rollt zurück.
- **Teile:** Gerade, Kurven, Anstieg, Abfahrt, Looping, Bremse, Booster, Splash (durch einen Teich) und Korkenzieher.
- **Level:** Hindernisse, begrenzte Teile und rot-weiße Pflicht-Flaggen, über die die Strecke führen muss. Bis zu drei Sterne pro Level, dazu Abzeichen.
- **Umfang:** 24 Level in 4 Landschaften (Wiese, Winter, Wüste, Küste) und ein Zufallsmodus, der neue Level aus allem erzeugt, was schon freigespielt ist.
- **Fahrt:** Gäste reagieren mit Sprechblasen; nach einer erfolgreichen Fahrt dreht der Zug weiter seine Runden.
- **Hilfe:** Tipp-Knopf, Erklärungen beim ersten Auftreten neuer Teile, Übersicht aller Teile.
- **Ton:** Drehorgelmusik, Geräusche und fröhliche Fahrgast-Stimmen – alles im Spiel synthetisch erzeugt; per Knopf abschaltbar.

## Status: experimentell

Das Projekt ist ein privates Hobby- und Lernprojekt. Es ist **nicht kommerziell**, unfertig und kann sich jederzeit ändern; Spielstände können bei größeren Änderungen zurückgesetzt werden.

## Spielen

`index.html` herunterladen und im Browser öffnen – oder, sofern GitHub Pages für dieses Repository aktiviert ist, unter `https://lepettre.github.io/mini-coaster-kingdom/` spielen. Auf dem iPhone lässt sich die Seite über „Zum Home-Bildschirm“ wie eine App ablegen.

## Für Entwickler

### Ordner
| Pfad | Inhalt |
|---|---|
| `hb4/logic.js` | Regeln, Teile, Physik (Schwung), Löser `solve`, Tipp-Löser `solveFrom`/`hint`, Hängenbleiben |
| `hb4/render.js` | Zeichnen: Gelände, Strecke, Looping, Korkenzieher, Wagen, Gäste, Ziel-Tor |
| `hb4/ui.js`, `hb4/template.html` | Oberfläche, Pixelschrift, Menü, Level, Hilfe, Zufall; `template.html` ist das HTML-Gerüst mit Platzhaltern |
| `hb4/sound.js` | Musik, Geräusche und Stimmen per WebAudio |
| `hb4/genb.js` | Zufallsgenerator im Browser |
| `hb4/phase2.js`, `varianz.js`, `layouts.js`, `addsols.js` | Erzeugen der festen Level und ihrer Musterlösungen (Node) |
| `hb4/levels24.json`, `pool.json` | Leveldaten, fester Vorrat an Zufallsleveln (Rückfall) |
| `hb4/station_*.json` | fertige Stationsgrafiken der 4 Landschaften |
| `hb4/build.py` | setzt alles zu `index.html` zusammen |
| `hb4/*test*.js` | Tests (Browser per Puppeteer; `phystest.js` reines Node) |
| `icons/` | Icon-Generator |

### Bauen und testen
```
npm install
cd hb4
python3 build.py        # erzeugt ../index.html
node phystest.js        # Physik + Lösbarkeit aller Level und Vorrats-Level (ohne Browser)
node test3.js           # alle 24 Level im Browser durchspielen
node stalltest.js       # Hängenbleiben und Zurückrollen
node test2.js           # Menü und Zufallsmodus
node soundtest.js       # Ton, Hörprobe nach out/hoerprobe.wav
```

### Wie das Bauen funktioniert
`build.py` ersetzt in `template.html` die Platzhalter `/*LOGIC*/`, `/*GENB*/`, `/*RENDER*/`, `/*UI*/`, `/*SOUND*/`, `/*LEVELS*/`, `/*POOL*/`, `/*STATIONS*/` und `<!--ICON-->` durch die Dateiinhalte. Spiel-Code gehört deshalb in die Quelldateien, nicht in die fertige HTML.

### Testhook
Im Spiel gibt es `window.__hb` (Zustand, Tap-Flächen per ID, Level wählen). Die Browser-Tests tippen damit echte Knöpfe.
